# BotBounty Agent

Agent expérimental pour rechercher et préparer des tâches BotBounty.

## Sécurité
- Aucune clé privée crypto dans le dépôt.
- Les secrets seront fournis uniquement via variables d'environnement.
- Le mode simulation est activé par défaut.
- Aucun paiement ou transfert automatique dans cette première version.

## Démarrage

```bash
python -m botbounty_agent
```
